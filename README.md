# 価格.com検索ツール
価格.comの検索URLを登録し、ヒットした件数を返すツール。
主な使い方は、0件になるような検索条件で、スケジューラで1日1回自動実行するとした場合、
1000円のPCを検索　→　普段0件なので通知なし　→　翌日、1000円のPCを検索　→　商品が登録されていたら「1件発見しました！」とウインドウ表示
と、ヒットした時のみ通知するように設定するのが便利。

## 1. 概要

価格.comの検索結果を定期的に確認し、検索条件に一致する商品が1件以上見つかった場合に、WindowsGUI上で件数通知ウィンドウを表示するためのツールです。

- `config.txt` に指定したURLと価格を元に、検索結果ページから、該当商品の件数を取得します。
- 該当商品がある場合は通知ウィンドウを表示し、ボタンから検索結果ページを開けます。
- 実行結果やエラーをログファイルに記録します。

## 2. 動作環境

- **制作環境：** Windows 11 / Python 3.15 で作成
- **必要なライブラリ：**
  - `requests`
  - `beautifulsoup4`
- **ファイル構成：** `main.py` と同じフォルダーに `config.txt` を配置
- **ネットワーク：** インターネット環境があること

### pythonが無い場合のセットアップ

1. Python 3 をインストールします。
2. コマンドプロンプトで、必要なライブラリをインストールします。

   ```bash
   python -m pip install requests beautifulsoup4
   ```

3. 本ツールの `main.py` と同じフォルダーに `config.txt` を用意します。

## 3. 使い方

### ① 設定

プログラムと同じフォルダーにある `config.txt` をテキストエディターで開き、各項目を設定します。

- 検索対象のURLをブラウザからコピって `SearchUrl=` の後に指定します。
- 価格上限を指定する場合は `TargetPrice=` の後に金額を入力します。
- ログの保存先を `LogFile=` の後に指定します。
- ツールを動作させる場合は `Trigger=ON`、停止する場合は `Trigger=OFF` にします。（一時停止用）
>>Trigger=OFFの場合は、起動した旨のログだけ出力して、何もせずに終了します。

### ② 起動

Pythonファイルを実行します。

```bash
python main.py
```



### ③ 通知

検索結果に該当商品が1件以上ある場合、通知ウィンドウが表示されます。

- **検索結果を開く：** ブラウザーで検索結果ページを開きます。
- **閉じる：** 通知ウィンドウを閉じます。

該当商品が0件の場合は通知ウィンドウを表示せず、ログに結果を記録して終了します。

### ④ ログの記録

`LogFile` に指定したファイルに、検索結果の件数、設定価格、検索URL、エラー情報などが記録されます。

`Trigger=OFF` の場合も、ログに記録されます。

### ※ 定期実行について

Windowsのタスク スケジューラに登録すると、指定した時刻に定期実行できます。

定期実行する場合は、Pythonの実行ファイル、スクリプトのパス、作業フォルダーを正しく設定してください。

```ini
操作：プログラムの開始
プログラム/スクリプト：Python.exeの位置（フルパス推奨）
引数の追加：main.pyのフルパス
開始（オプション）：main.pyを置いたフォルダのフルパス
```

## 4. config.txt の設定方法

`config.txt` は、動作条件を指定する4行からなるファイルです。

### 設定例

```ini
SearchUrl=https://kakaku.com/pc/gaming-mouse/itemlist.aspx?pdf_Spec202=6
TargetPrice=5000
LogFile=D:\logs\kakakucom.log
Trigger=ON
```

※ 上記の例で「5000円以下の6ボタンゲーミングマウス」を検索します。主な用途としては、検索結果が0になるような価格設定（1000円以下とか）を毎日検索して、1000円以下の商品が1件でも出現したら通知する、というのが有用かと思います。

### 設定項目一覧

| 項目 | 必須 | 説明 |
|---|---|---|
| `SearchUrl` | 必須 | 価格.comの検索結果URLを指定します。 |
| `TargetPrice` | 任意（空欄可） | 価格上限を整数で指定します。例：`10000` は10,000円以下。 |
| `LogFile` | 必須 | ログファイルの保存先を指定します。相対パスの場合、作業フォルダーが基準になります。 |
| `Trigger` | 必須 | `ON` または `OFF` を指定します。`OFF` の場合は検索を行いません（タスクスケジューラを有効／無効にするのが面倒なとき用） |


---

## 補足

本ツールは価格.comのページ表示・応答に依存します。サイト側の仕様変更、通信障害などにより、検索結果の取得に失敗する場合があります。
